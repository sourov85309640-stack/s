## Bugs
QC-1 HIGH. Reload at scroll depth (and resize while pinned) leaves the 3D model collapsed. Repro: 1440x900, scrollTo(top+1.3*vh), reload, wait. Model --s=0 (layers stacked in a muddled grid, see shots/qa_c_reload_depth.png) while list shows "Underlay" open and nothing highlighted; stays until the first wheel tick (s becomes 1). Same after resizing 1440x900 -> 1100x800 while pinned: --s=0 even when scrolled past the pin end (rafters pressed). Cause: motion.js exploded(): matchMedia setup sets o.s=0 then write(); the scrub timeline's onUpdate:write does not fire after ScrollTrigger refresh restores progress, while peel() runs from the trigger's own onUpdate. Fix: in the ScrollTrigger config add onRefresh:function(self){tl.progress(self.progress);write();} (or tl.totalProgress then write on 'refresh' event), and also write() inside peel().
QC-2 MED. "See how an inspection works" button falls below the viewport while pinned at heights 720-745 and widths 900-1200. 900x720: btn bottom 764; 1024x720: 738; 1100x720: 741; 1280x720: 714 (6px spare). Cause: the open description adds 22-43px to .whole-copy after the pin spacer height was measured, and pin start is top = HDR+16 so there is no slack. src/motion.js pin start, src/styles.css .xv-list .d / .whole-grid. Fix: raise pinned min-height to (min-height:780px), or give .whole-copy a fixed height reserving the open-row height, or shrink .lead margin.
